# Student Grade Calculator

## Day 2 - AI & ML Internship

This project is a Python program that calculates grades for students based on their marks.

## Grading Logic

| Marks | Grade |
|---|---|
| 90–100 | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| 40–49 | E |
| Below 40 | F |
| Below 0 or Above 100 | Invalid |

## Features

- Calculates grades using if, elif, and else.
- Handles invalid marks.
- Tests different marks.
- Displays marks and assigned grades.

## Tools Used

- Python
- Jupyter Notebook
